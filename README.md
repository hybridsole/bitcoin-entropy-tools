# ₿ Hybrid's Bitcoin Address Tools

> **A 100% offline, standalone HTML tool for generating secure Bitcoin private keys, BIP-39 seed phrases, and addresses using true physical entropy.**

[![Security: Air-gapped](https://img.shields.io/badge/Security-Air--Gapped_Ready-blue.svg)]()


Live version available at https://bitentropy.org

Github hosted version at https://hybridsole.github.io/bitcoin-entropy-tools/bitentropy.org.html

Hybrid's Bitcoin Address Tools is engineered specifically for individuals who want complete cryptographic self-sovereignty. By relying on physical entropy (dice, coins, or mouse movements) and running entirely client-side without internet access, this tool eliminates reliance on third-party random number generators (RNGs) and network-connected wallets.

Everything—including the SECP256K1 elliptic curve math, SHA-256 hashing, and QR code generation—is bundled into a single, highly readable `bitentropy.org.html` file.

## ✨ Features

*   **True Physical Entropy:** Generate your 256-bit root secret using:
    *   🪙 Coin Flips (D2)
    *   🎲 Dice Rolls (D6, D10, D12, D16 Hex, D20)
    *   🃏 Deck of Cards (52-card deck)
    *   🖱️ Micro-timing Mouse Movement Vectors
*   **All Major Address Formats:** Automatically derive:
    *   Native SegWit / P2WPKH (`bc1q...`)
    *   Taproot / P2TR (`bc1p...`)
    *   Legacy / P2PKH (`1...`)
    *   Nested SegWit / P2SH (`3...`)
*   **BIP-39 HD Wallets:** Generate 12-word or 24-word seed phrases with optional passphrase protection, calculating the 512-bit master seed and derivation paths (m/84', m/44', m/86', etc.).
*   **WIF & Public Keys:** View compressed and uncompressed Wallet Import Formats (WIF) and exact 33-byte hex public keys.
*   **Paper Wallet Generation:** Includes a built-in, printer-friendly CSS layout designed specifically for creating cold-storage paper backups.
*   **Wallet Utilities:** Convert private keys, create multisig addresses, xpub viewer, raw transaction decoder, key typo resolver, air-gapped webcam qr scanner, and more.
*   **Zero Dependencies:** No external scripts, CDNs, or web calls. Inspect the code yourself.

## 🛡️ Security First: How to Use Safely

This tool is designed to be used in a completely **air-gapped environment**. Generating private keys on a machine connected to the internet exposes you to malware, keyloggers, and clipboard hijackers.

### The Recommended Cold Storage Protocol:
1. **Download** the `bitentropy.org.html` file from the [Releases](#) page to a trusted, everyday computer.
2. **Transfer** the file to a clean USB flash drive.
3. **Boot** an offline, air-gapped computer (preferably running a live OS like [Tails](https://tails.boum.org/) or a fresh Linux installation without Wi-Fi/Ethernet).
4. **Open** the `bitentropy.org.html` file directly in the offline machine's web browser.
5. **Generate** your keys using physical dice or coins. 
6. **Write down** your WIF private key or BIP-39 Seed Phrase on physical paper.
7. **Shut down** the live OS (which wipes the system's RAM) before ever connecting to the internet again.

## 🔍 Don't Trust, Verify

Cryptographic self-sovereignty means verifying the math yourself. You do not have to trust this tool. 

The application includes a **"Don't Trust, Verify"** modal that provides instructions on how to take the raw entropy text you input (e.g., your exact dice rolls or coin flips) and verify it against independent, offline command-line tools. 

You can manually prove that the SHA-256 hash digest generated by this tool perfectly matches the mathematical output of standard cryptographic libraries on your machine.

## 📥 Installation & Usage

Because this is a standalone tool, there is no compilation, build step, or installation required.

1. Navigate to the **[Releases](../../releases)** tab on this repository.
2. Download the latest `bitentropy.org.html` file.
3. Double-click the file to open it in any modern web browser (Chrome, Firefox, Safari, Brave, Edge).
